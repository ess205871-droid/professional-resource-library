# 专业资源库 · 交互演示

由 Figma 设计稿还原的静态演示页面（含轮播、悬停、分类切换等交互）。

## 文件说明

- `index.html` — 演示入口，引用 `assets/` 相对路径，可在线预览
- `index-source.html` — 设计源文件版本（引用本机绝对路径，仅供本地存档）
- `assets/` — 页面切图素材
- `fonts/` — 内嵌字体（阿里巴巴普惠体 / D-DIN）
- `d2d-context.md` — 还原过程记录（骨架参数、对齐校核、交互改动）

## 本地查看

下载整个仓库，直接用浏览器打开 `index.html` 即可。
